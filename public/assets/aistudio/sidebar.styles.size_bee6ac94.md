# Sandbox Sidebar Styles And Size Tokens

## Audit Scope

Source: canonical [`sandbox/index.html`](../index.html). This review-only ledger records authored styles and sizing declarations for the host activity rail, secondary sidebar/drawer and its rendered activity-specific content, plus SQL Studio's separate iframe sidebar. It includes all 13 host sidebar renderer variants as a selector union; repeated UI states are not counted as duplicate CSS sources.

Included styles cover dimensions, layout, spacing, typography, colors/backgrounds, borders/radii, overflow, positioning, transitions, focus/active/hover states, and responsive overrides. The titlebar navigation dropdown is a separate menu and is not included. Generic reset/control rules are included only where they apply to sidebar descendants. Values using semantic variables remain literal references.

The raw CSS inventory contains 96 host rule groups (454 declarations) and 16 SQL Studio sidebar rule groups (83 declarations). The rendered host sidebar union yielded 15 inline style occurrences across four source patterns; SQL Studio sidebar elements have no inline styles. Inline background values are dynamic expressions sourced from collection colors or tool gradients.
