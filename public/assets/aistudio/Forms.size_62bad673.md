# Sandbox Form And Input Size Tokens

## Audit Scope

Source: canonical [`sandbox/index.html`](../index.html). This review-only inventory records explicit size-related CSS for form layouts, text inputs, selects, textareas, checkboxes, color/range controls, and radio-style review controls. Host and generated mock-tool iframe styles are kept separate. Typography values are included where they size control text; see [`fonts.md`](fonts.md) and [`fonts.size.md`](fonts.size.md) for the complete typography ledgers.

The current rendered markup includes text, search, URL, email, file, checkbox, color and select controls, textareas, and custom star choices with `role="radio"`. There are no native `input[type=radio]` declarations in the source. Repeated controls in multiple rendered pages are not treated as unique design tokens. No inline size styles were found on rendered host or mock form controls.

Values below are literal source declarations. Browser-native defaults are not presented as authored dimensions.

## Inline And Coverage Notes

- No inline geometry was found on rendered host or mock native form elements. The Password Generator mock preview has inline sizing on the checkbox group row and its four labels: `.row` uses `gap:16px; font-size:13px; flex-wrap:wrap`, and each checkbox label uses `display:flex; gap:6px; align-items:center; flex:none`.
- Page-shell bounds, generic panel/table geometry, and mock iframe app frames are cross-referenced in [`Pages.size.md`](Pages.size.md), [`Sections.size.md`](Sections.size.md), and [`cards.size.md`](cards.size.md); they are not duplicated here unless they directly size a form/control group.
- The rendered host inventory spans text/search/url/email/file inputs, selects, textareas, checkboxes, a color input, and `role="radio"` buttons. Generated preview controls include textareas, a color input, a range input, and checkboxes.
- The CSS extraction includes form wrappers and responsive overrides so dimensions are not reduced to individual input boxes alone. It preserves authored declarations rather than inferring native control sizes.
- Refresh this audit whenever form/control markup or sizing in `sandbox/index.html` changes. This is a source inventory, not a production form-system contract.
